燧镜 {VERSION}
作者：{AUTHOR}

====================================================

【这是什么】
一块常驻托盘的 PC 游戏助手面板：打游戏前后要开的那些小工具，全收进一个窗口。

双击程序 = 打开面板（不会直接改分辨率）；点右上角 × 只是收进托盘，后台继续跑。
窗口每次打开都摆在屏幕正中间，不用再自己拖。

面板分七页：主页 / 内置工具 / 工具 / 模组 / 音乐 / Steam / 喜加一。
右上角是 游戏模式 / 自动化 / 日志，再往右依次是 音频输出、设置齿轮、皮肤、分辨率框。

· 画面：分辨率一键切档、回原生，多屏各切各的，黑边判定 + 显卡缩放指引
· 战斗：截图、录屏（带声音）、最近 10 分钟回放、素材按日期归档、发出去前打码
· 状态：CPU / 内存 / 显卡 / 温度实时监控，游戏里还有帧率灯
· 情报：三角洲每日密码（可挂屏幕侧边、鼠标穿透）、子弹价格、假账榜、制造利润
· 音乐：网易云 / QQ音乐 / 酷狗 / 酷我 四个平台各自搜歌播放；窗口内灵动岛 +
  桌面悬浮条，玩游戏时不切回来也能暂停切歌
· 游戏库：Steam 库直读本机记录，封面墙里装了的直接启动；喜加一列 Epic 免费
· 手机：同一个 WiFi 直连（网页或 App），看状态、互传文件、同步剪贴板、遥控音乐
· 投屏：手机画面进电脑，鼠标键盘直接反控手机，插线或无线都行（详见下面章节）
· 工具：把别的程序 / 网页挂进来，统一启动停止；已下载的排在上面，
  没下载的三方推荐工具排在横线下面（标「三方工具」），点一格就去官网
· 内置工具：跟游戏直接相关的自带小工具（反作弊优化、准星、电源计划、工具箱）
· 模组：只认 .sjmod 扩展包，拖进去就装好，能力按包里的清单放行
· 系统：ACE 扫盘限流、着色器缓存清理、网络测速、推迟 Windows 更新、
  音频输出一键切换（耳机 / 音箱按 Alt+Z）、显示器滤镜（18 个预设）
· 游戏模式：顶栏一键把壁纸收起、监控采集降到 6 秒、电源计划切高性能；
  再点一下或退出程序，全部放回原样
· 提示：不管开工具、切游戏模式还是投屏连上断开，都在窗口顶部中间那条小胶囊里
  闪一下（跟游戏模式开关用的是同一个位置），两秒多自己淡出，
  不会弹到屏幕外面，也不会压着顶栏文字

想秒切分辨率：Ctrl+Alt+R；也可以建个快捷方式写 "燧镜.exe --toggle"。

====================================================

【怎么装】
两种都行，用哪个都一样的程序：

· 安装版：双击「燧镜_{VERSION}_安装包.exe」，下一步到底。
  默认装到 C:\Users\你的用户名\AppData\Local\Programs\燧镜（不需要管理员，
  素材能直接写进去），会自动建桌面和开始菜单快捷方式，控制面板里能卸载。
  想装到 D 盘就在安装界面点「浏览」改路径。
· 解压版：把整个文件夹解压到任意位置，双击 燧镜.exe 就能用。

升级：直接再跑一遍新安装包，装到同一个目录就行。
      安装前它会把你的 config.json 备份一份，装完原样放回去 —— 自己加的工具、
      皮肤、热键、素材位置都在；素材和截图录像本来就不动。
      就算手滑装到了别的目录，安装器也会去注册表翻上一次的安装位置，
      把那边儿的 config 带过来（全新目录实测过，自己加的 10 条工具全在）。
      也可以在软件里「设置 → 版本与更新 → 检查更新」：把新安装包放进
      「下载」文件夹，它会自己认出更新的版本，点一下就装，装完自动重开。

  如果这会儿正插着手机投屏，安装器会先帮你把 adb / scrcpy 关掉再覆盖写文件 ——
  以前 adb 还占着文件时，装到这里会弹「无法打开要写入的文件 AdbWinApi.dll」。
  装完再点一次投屏就行，效果一样。

卸载：设置 → 应用 → 燧镜 → 卸载。会问你要不要连素材一起删，选「否」
      就只删程序，截图录像和配置留在原目录，以后重装能接着用。

注意：要 ACE 限流、改分辨率、推迟系统更新这些动系统的功能，得右键
「以管理员身份运行」；只是看面板、截图、录屏、投屏不需要。

====================================================

【第一次使用】

1. 双击 燧镜.exe（打开面板，窗口就在屏幕正中）
2. 程序会自动识别你这台电脑的屏幕分辨率，并记录下来作为"原生基准"
3. 目标档位已经替你选好了：程序按你屏幕的原生分辨率配一个同比例的档位
   （1080p 屏 → 1600×900，2K 屏 → 1920×1080），比例一致所以不会出黑边。
   想改就自己在下拉里挑，挑过一次程序就不再动它。
4. 点面板上那个大按钮看效果；不合适就点"恢复原生"或换个目标档
5. 直接关闭窗口，程序会收进托盘继续在后台跑
6. 之后双击程序图标 = 打开面板；秒切用 Ctrl+Alt+R

====================================================

【重要，务必看完】

1. 不要把 燧镜.exe 单独挪走！
   必须和同目录的 _internal 文件夹一起使用，缺了它程序打不开。
   想移动到别处，就把整个文件夹一起剪走。

2. Windows 首次运行可能提示"Windows 已保护你的电脑"，
   或者杀毒软件报警 —— 这是未签名的自写工具被误判。
   点"更多信息 → 仍要运行"，或把整个文件夹加入信任区。
   想核对文件没被人改过：打开顶部「关于」，有一行 SHA256，点「复制指纹」就能复制。

3. 分辨率切坏了、屏幕变糊、想强制回去：
   双击 恢复分辨率.bat
   这条路径不加载界面，即使主程序卡死也能恢复。

4. 快捷键：
   Ctrl + Alt + R  切换档位 / 恢复原生
   Ctrl + Alt + M  打开面板
   Ctrl + Alt + S  全屏截图      Ctrl + Alt + Shift + S  框选截图
   Ctrl + Alt + V  开始/停止录屏  Ctrl + Alt + B  保存最近回放
   以上全部可以在「设置 → 热键」里改：点一下那个按钮，直接按你想要的组合。
   某个组合被别的软件占用了，程序会自动换一个备用键，并明确告诉你换成了什么。

5. 投屏用的是随包带的 adb：投屏开着的时候，手机在开发者选项里的「USB 调试」
   别关；关了就得重新点「手机投屏」走一遍授权。

====================================================

【它都能干什么】

· 音乐：网易云 / QQ音乐 / 酷狗 / 酷我 四平台，各自搜歌、播放、读账号歌单与每日推荐
  登录点右上角「登录XX」，弹窗里写着该平台怎么登（有的扫码，有的贴 cookie）
· 窗口灵动岛：只有放歌时才出现在窗口顶部中间。紧凑态是一条声纹律动 + 三个按钮，
  点一下原地放大，多出封面、歌名、歌手、可拖动的进度条和音量条，缩回去位置不变
· 桌面悬浮条：另一条独立小窗，浮在屏幕上，主窗口收进托盘也照样在 ——
  玩游戏时不用切回来就能暂停 / 切歌；按住条上空白处能拖，拖到屏幕左右边缘
  松手自动贴边收起，鼠标碰一下自己展开。音乐页顶部有开关，关掉就完全不出现
· 手机互联：同一个 WiFi 直连，不走公网、不经过任何服务器。手机浏览器打开面板给的
  地址，能看电脑状态、互传文件（电脑发手机、手机传电脑）、同步剪贴板（最近 10 条）、
  还能遥控电脑上的音乐播放。手机传来的文件存哪，在 设置 → 手机传来的文件 里改
· 手机投屏：主页右边那个方块，点开就是投屏面板，手机画面进电脑、鼠标键盘反控，
  画质三档、无线也行。细节看下面【手机投屏怎么用】
· 手机版 App：主页右边「连接手机」方块点开，二维码和 6 位配对码一块给你。
  App 里三种连法随便挑：自动发现（同一个 WiFi 自己扫出来）、扫码（相机对着弹窗里
  的二维码）、填配对码（6 位数字，10 分钟换一次，用掉就作废）。
  手机不想看到电脑剪贴板，就去 设置 → 手机 · 剪贴板 把开关关掉，别的不受影响
· 手机版壁纸：手机页面 设置 → 壁纸，从手机相册挑一张当背景，只存在手机本地
· 分辨率：一键切目标档位 / 回原生，Ctrl+Alt+R 秒切
· 游戏模式：顶栏「游戏模式」一点 —— 壁纸收起、监控采集从 2.5 秒降到 6 秒、
  电源计划切高性能；再点一下或退出程序，这几样全部放回原样。
  切换时窗口顶部中间那条岛会闪「游戏模式已开启 / 已关闭」，标签也会变成 GAME MODE
· Steam 库：直接读本机 Steam 记录，装了什么、装在哪、玩了多久都列出来，
  不用填 SteamID。封面墙 4 列，装着的给「启动」，没装的给「查看商店」
· 喜加一：Epic 本周正在免费和即将免费的都列出来，点「立即领取」用浏览器打开商店页。
  这页不登录、不代领
· 工具：把别的程序、网页当成工具挂进来，统一启动停止；没下载的三方推荐
  排在横线下面，点一格就去官网
  内置 5 条随包走：口琴可视化曲谱、手机音频接收（蓝牙把手机声放进电脑）、
  qBittorrent（BT 下载，4.6.5）、三角洲情报、显示器滤镜
  qBittorrent 的配置缓存都在 bundled\qbittorrent\profile 里，不写 %APPDATA%、
  不装服务、不建快捷方式、不关联 .torrent，中文界面，首次的许可和更新弹窗已跳过；
  不想用了直接删 bundled\qbittorrent 就干净。它是 GPL-2.0 开源软件，
  许可证见 bundled\qbittorrent\LICENSE.txt
· 显示器滤镜：不用另装软件，点「打开页面」调显示器伽马曲线 —— 提亮、抬暗部、
  偏暖偏冷、加对比；18 个预设（去曝光、鲜艳、电影、高亮、柔和、游戏、阅读、
  暗部增强、偏暖、偏冷、冷色调、原亮冷调，外加三角洲推荐 1~5 和超级推荐），
  右边还能细调色温 / 亮度 / 对比 / 伽马 / S 曲线 / 红绿蓝增益，
  上面左边原图右边滤镜做对比。只改显示器输出曲线，不注入、不叠画面层；
  关窗或退出自动还原，另有「还原」按钮，托盘「全部还原」也一起归位
· 三角洲情报：每日密码（可开常驻悬浮窗，贴屏幕左/右侧、鼠标穿透）、
  子弹自选包、假账榜、制造利润，数据来自 shushu.fan，手动刷新
· 帧率灯：游戏里显示 FPS / 帧时间，独立开关，可拖动、可设鼠标穿透
· 系统监控：CPU、内存、显卡占用与显存、显卡温度，超过 85% 变红
· 截图：Ctrl+Alt+S 全屏、Ctrl+Alt+Shift+S 框选、还有 3 秒延迟版
  框选拖完不是松手就存：先给一个对勾一个叉号，点对勾才落盘，
  不满意点叉号 / Esc / 右键就能原地重框
· 录屏：带系统声音
· 回放：一直存着最近 10 分钟，Ctrl+Alt+B 一键保存，也带声音
· 素材归档：截图 / 录像按日期自动分到 素材\录像\年-月-日
  素材能换盘：设置 → 高级 → 素材存放位置，选盘或自选文件夹都行；
  换的时候旧素材可以一键搬过去（日期目录保留），也可以只换位置旧的留着。
  回放缓存（只存最近 10 分钟）的盘是紧挨着它上面那一项单独设的
· ACE 限流：限制扫盘进程优先级，可选守护模式自动补刀；打完一键还原
· 着色器缓存清理：NVIDIA / AMD / Intel / DirectX 缓存目录一键清
· 网络测速：连采 12 秒，看延迟抖不抖、丢不丢包，最后直接说"卡是网络的锅还是机器的锅"
  在 设置 → 高级 里填一个游戏服地址，它还会额外打那一台，单独给一行延迟
· 系统更新推迟：一键把 Windows 更新往后挪 30 多天，免得打到一半被拽下去
· 音频输出切换：耳机 / 音箱按 Alt+Z 秒切，托盘还挂个小喇叭双击就切，
  切换时屏幕左上角飘一张提示卡，2 秒自己淡出，鼠标能穿过去
· 托盘"全部还原"：出任何事先点它 —— 存回放、关缓冲、关灯、关悬浮窗、
  ACE 还原、分辨率回原生、显示器滤镜归位，一口气回到默认
· 素材页：缩略图、按日期/类型搜索、看占用、删这一天、清理旧素材
· 素材页会标每段录像的时长和有没有声音：卡片第二行写 "0:20 · 有声 · 19.7 MB"
  或 "0:05 · 静音 · 3.4 MB"，不用点开播放器；时长直接扫 mp4 头部读出，不解码
· 素材页顶部下拉能筛：全部素材 / 只看截图 / 有声录像 / 静音录像 / 坏档
  筛完顶部汇总跟着变（"筛出 2 个 · 13.1 MB"），不会出现 2 个文件却 70MB 这种数字
· 素材打码：截图右键"打码（遮住账号 / 昵称）"，在图上拖几块就是马赛克，
  另存一张"原名_打码.png"，原图不动 —— 发出去前遮住账号信息
· 外观：设置 → 外观。皮肤有赛博青 / 暗金 / 纯黑三套，点哪套用哪套；
  壁纸开关打开后垫一张铺满整窗的半透明图，也能选自己的图（png/jpg/webp/bmp）；
  窗口外观可选经典 / 毛玻璃 / 液态玻璃，后两种没有系统标题栏、四角圆、
  能透出背后桌面，背景模糊 0~40 自己拉，默认 18。旁边那个齿轮进设置，小衣服换皮肤
  毛玻璃 / 液态玻璃下，工具卡片是深色玻璃（亮边 + 大圆角 + 半透明），不是蒙灰的色块
· 更新日志：关于页右下角，按日期列出每次改了什么
· 工具健康检查：工具起不来会标红"启动失败"，鼠标悬停直接给原因
  （缺运行库 / 要管理员 / 被占用 / 下错版本 / 被杀毒拦）
  第一次没起来会自动再试一次，还不行才标红（原因后面标"已自动重试过一次"）
· 全部启动：按列表从上到下依次起，每个隔 0.8 秒，前一个站住再起下一个
· 托盘状态开关：帧率窗 / 回放 / 录屏 / ACE 限流 / 密码窗，勾着就是开着，
  点一下就切，不用开面板就知道现在什么在跑
· 多屏：分辨率卡下面有"作用屏幕"下拉，选哪块切哪块，别的屏不动
· 自动化：预设流程「开战：等 30 秒 → 限 ACE → 开帧率灯 → 开回放缓冲」
  「收尾：存回放 → 停回放缓冲 → 关帧率灯 → 回原生」，也能自己编排 18 种动作
· 换电脑自动识别：到别人机器上只更新"原生基准"，绝不动当前分辨率

====================================================

【手机投屏怎么用】

1. 主页右上角那个「手机投屏」方块（跟「连接手机 / 文件互传」同一列，
   落点和 CPU / 内存那一行齐平），点一下就开投屏面板。
2. 第一次要先把手机的准备做好：设置 → 关于手机 → 连点版本号开「开发者选项」，
   再进去打开「USB 调试」，插上数据线。
3. 面板会先说清楚现在卡在哪一步：
   · 没连上 = 它把开调试的四步列出来，照着点
   · 手机弹了授权框 = 去手机屏幕上点「允许 USB 调试」
   · 真连上了 = 「开始投屏」才亮起来
4. 画质三档：流畅 / 标准 / 高清，按线材和手机挑，糊一点但跟手就选流畅。
5. 无线投屏：先在「连接手机」那边扫过码或输过配对码的手机，投屏面板的
   无线地址已经给你填好了，不用去手机设置里抄 IP。
   第一次切无线还是要插一次 USB 线点「允许 USB 调试」，这是 Android 的规矩，
   切过之后拔线也能投。
6. 面板上三个按钮各管各的：
   ·「开始投屏」真的把手机画面拉到电脑上
   ·「收起面板」只把小窗收掉，投屏照旧在跑，想看再点方块打开
   ·「结束投屏」才真断开
   直接关掉那个投屏窗口 = 结束投屏；关掉燧镜也会一起断，不留后台进程。
7. 投屏期间手机自己那块物理屏会熄掉（省电也不碍事），但连接保持唤醒不掉线；
   主页那块方块的标题会变成「投屏中」，一眼看得出现在开着。

【手机版 App 怎么装】

· 同目录里有 燧镜手机版_v1.0.7.apk，这是安卓包（苹果手机装不了）。
  找不到就在软件里点 主页 → 连接手机 → 获取 App，它直接把那个文件夹打开、
  帮你选中 apk。
  把 apk 传到手机上点开安装，第一次会提示「未知来源」，允许这一次就行。
· 装完打开 App：同一个 WiFi 下一般自己就把电脑扫出来了，列表里点一下就进；
  扫不出来就用扫码（对着电脑端弹窗里的二维码），或者手填那 6 位配对码。
  电脑换了 IP，App 会在同一个网里自己找回来，实在找不到才让你重连。
· 电脑端必须先开着燧镜。配对码在 主页 → 连接手机 里看，10 分钟换一次；
  连错 5 次这串就作废，会换新的一串。
· 电脑那边断了（睡觉 / 退出 / 换 WiFi），手机页面会出一张断线卡片，
  写着可能的原因和「马上重连」「换一台电脑」两个按钮，电脑回来卡片自己消失。
· 电脑发过去的文件会真落到手机「下载」文件夹里，文件管理器能翻到；
  手机文件页还有个按钮，一点直接调起文件管理打开那个文件夹。
· 不想装 App 也行：手机浏览器直接打开那个地址，功能一样，只是没有图标。
· App 现在是 1.0.7，跟着电脑端一起更新；电脑端升级了 App 不用重装。

【音乐页怎么登录】

· 网易云：软件里直接出二维码扫就行，最快，不用开网页。
· QQ音乐 / 酷狗 / 酷我：点登录会弹出一个小窗，里面是它们自己的官网。
  在那个窗口里扫码或者输账号，登进去以后点「我登好了」，软件会把登录信息抄下来，
  下次开软件不用再登（酷我除外，它的登录态本来就是关窗口就失效的，软件会替你存着）。
· 这几个窗口是联网加载真网页，第一次打开慢一点，等页面出来再操作。
· 提示「没读到登录信息」时：先看窗口右上角是不是你的账号。确实是账号还认不出来，
  就点左下角「手动贴 cookie」走老办法。
· 酷我的每日推荐拿不到账号自己的那份（它把第三方请求一律拒了），
  软件会用热门歌手凑一份，是热门歌，不是按你口味算的。
· 酷狗 / 酷我只能听免费的；会员歌能不能听得看那个账号本身有没有会员，
  跟登没登录是两回事。

【工具怎么用】

- 顶部按钮：
    「图标 / 列表」  同一个工具页的两种排法，图标是宫格磁贴，列表是一行一条
    「全部启动」    按列表从上到下依次起，每个隔 0.8 秒
    「+ 添加工具」  选 .exe / .bat / .html，或者直接粘贴一个网址；
                    也能选「三方工具（填官网链接）」，只填名字和官网就行
    最右边「⋯」     导出工具清单… / 导入工具清单…
- 已下载的排在横线上方，没下载的三方推荐排在横线下方，标着「三方工具」：
    点一格（列表里点卡片）就去官网；如果填了直链，就由燧镜下载到
    文档\燧镜\tools\工具名\ ，下完自动变成普通工具，直接能启动
- 每张卡片左边的勾选框：
    勾上 = 框架允许启动它，会出现在托盘右键的"工具"菜单里
    取消 = 从框架里屏蔽，灰掉不能启动（原文件不受影响）
- "随框架启动"：打开燧镜时自动把该工具一起拉起来
- 网页类（html / 网址）的按钮是"打开"，用默认浏览器打开。
  每次都是直接打开原文件，不复制不缓存，所以文件更新后打开就是最新的。
- 图标：程序用自己的图标；三方工具和网页类的图标由燧镜去官网抓一次，
  存在 cache\favicons\ 里，抓过的离线也能显示，抓不到才显示名字首字。
- 三角洲情报和显示器滤镜是页面类内置工具，卡片上写"内置"，
  按钮是"打开页面"，点了就在软件里切过去，不开浏览器。
- 升级不用重新加：自己加的条目都存在 config.json 里，安装包升级会原样带过来。
  换电脑或者想留一份底：点「⋯」→ 导出工具清单，会存成一个 json（只导自己加的，
  内置那几条本来随包走）；到新机器上点「导入工具清单」挑那个文件，
  按名字 + 路径去重后直接补进列表，不留重复卡。

【模组怎么用】

「模组」页是留给可安装扩展的，跟「工具」页不是一回事：

- 只认 .sjmod 包（本质是 zip：manifest.json + main.py + assets）
- 装：把 .sjmod 拖到模组页松手，或者在「+ 添加模组」里选文件；
  装坏的包会被挪进 mods\_invalid，不会卡住页面
- 装好以后在模组页显示成磁贴或列表，勾选 = 启用；点开有详情 / 打开目录 / 卸载
- 模组不能单独双击运行：包里不放 exe，入口靠燧镜注入，脱离燧镜打不开
- 自己写模组：看仓库 docs\MOD_API.md，打包用 tool\make_sjmod.py，
  自检用 tool\mod_test.py

【黑边怎么办 / 嘉豪模式】

切到 4:3 后左右有黑边，是显卡的缩放模式在"保持宽高比"，不是软件的问题。
面板上勾"嘉豪模式"，再点"去显卡设置"，去显卡面板改一次：

  NVIDIA：系统 -> 显示器（或控制面板 -> 调整桌面尺寸和位置）-> 缩放：模式全屏、设备 GPU
          如果设备只有"显示"且灰着（HDMI 高刷 + DSC），GPU 缩放这条路是关的，改用：
            （这种黑边是显卡画在画面里的，显示器收到的仍是 1920x1080 整幅图，
             所以改显示器 OSD 的画面比例没用）真正能拉满的只有：
            甲：游戏里分辨率设 4:3 + 显示模式选"独占全屏"，游戏自己铺满
            乙：换 DP 线再试，DP 跑高刷不需要 DSC，GPU 缩放可能解锁
  AMD：AMD Software -> 齿轮设置 -> 显示 -> 缩放模式 -> 整个面板
  Intel：Intel 显卡中心 -> 显示 -> 缩放 -> 拉伸

面板还会读你用的线（DP / HDMI）和刷新率，直接告诉你属于哪种情况：
   - 读到 DisplayPort：把缩放设备改成 GPU 就能铺满，不用换线
   - 读到 HDMI 且高刷（120Hz 以上）：GPU 缩放多半被驱动关了，走"乙方案"换 DP 线
   勾选嘉豪模式时弹的窗，第一行就是【这台的情况】。

改完是全局持久的，以后切分辨率自动拉满。
"显卡：自动"如果认错（双显卡笔记本核显独显都在，很常见），手动选成独显厂家就行。

接了两台以上显示器时，分辨率卡下面会写「检测到 N 台显示器：这键只切主屏」，
副屏不受影响，这不是 bug（想切副屏就在"作用屏幕"那一项里挑）。

【出任何事，先点这个】

右键托盘图标 -> "全部还原"（命令行也行：燧镜.exe --panic）
它按顺序做：录屏先保存并停掉 -> 关回放缓冲 -> 关帧率灯 -> 关密码悬浮窗
-> 显示器滤镜归位 -> ACE 全部还原 -> 分辨率回原生。
本来就在默认状态它会直说，不会瞎动。

分辨率切坏了最急的情况：双击 恢复分辨率.bat（不加载界面，主程序卡死也能救）。

【自动化 18 种动作】

三种触发：当某程序启动 / 当某程序退出 / 仅手动执行。
进程名要写任务管理器"详细信息"里的真名，不是窗口标题。

18 种动作（失败一律跳过这条、继续往下跑，不会卡死整套流程）：

  切换分辨率        指定档位，屏不支持就跳过，不会切黑屏
  恢复原生分辨率    回基准档
  启动模组          拉起对应程序
  停止模组          结束进程；网页模组不接管浏览器
  等待              秒数，给游戏加载留时间
  限制 ACE 扫盘     要管理员权限
  解除 ACE 限制     恢复原优先级
  开帧率悬浮窗 / 关帧率悬浮窗
  显示密码悬浮窗 / 隐藏密码悬浮窗
  开启回放缓冲 / 关闭回放缓冲
  保存最近回放      缓冲落盘成 mp4，10 分钟要合几秒
  开始录屏 / 停止录屏并保存
  截一张图          全屏 或 框选
  清理着色器缓存    清完第一次进游戏会重编译，略卡一下

配好先点"试运行"看它按不按你想的走，再勾启用。

【常见问题】

问：切完变糊 / 两边黑边？
答：黑边是显卡缩放设成"保持宽高比"，软件改不了。看上面【黑边怎么办】。
    变糊先按 Ctrl+Alt+R 回原生，不行双击 恢复分辨率.bat。

问：换别人电脑上会不会把我分辨率搞乱？
答：不会。只更新"原生基准"，绝不主动改当前分辨率。当前分辨率和面板最大
    对不上时，第一次运行会先问一句按哪个记。

问：工具点了没反应 / 一闪就没了？
答：卡片下面会自己给出结论，四种状态：
    · 未运行 = 没启动过或被停了
    · 运行中 = 活着
    · 文件丢失 = 那个 exe 不在原位了（换盘、挪过目录），编辑一下路径
    · 启动失败（红字）= 起来了马上退了，鼠标悬停看原因：
        缺运行库 -> 装 VC++ / .NET
        权限不足 -> 右键程序"以管理员身份运行"
        被占用 -> 关掉那个旧进程
        不是能在本机跑的程序 -> 下错版本（32/64 位或别的系统）
    每次都会写进日志，出问题点"导出诊断包"能一起带出来。

问：升级完工具没了，只剩内置那几条？
答：这么长时间碰过两回，都不是程序删的：一是装到了新目录、而老目录里的
    config.json 没被带过来（现在安装器会去注册表找上一次的位置，把 config 捞过来）；
    二是新装完还没开过、看着是空的。装到同一个目录升级，自己加的工具一条都不会丢。
    实在不放心就先点「⋯」→ 导出工具清单，装完再导入。

问：投屏点「收起面板」以后还要再点一次吗？
答：不用。收起只是把小窗收掉，投屏画面和手机连接都还在跑；
    再点主页那块方块就能把面板叫回来。要断开就点「结束投屏」或者直接关投屏窗口。

问：投屏一直卡在「还没连上手机」？
答：看面板里那四步：数据线是不是数据线（有些充电线只供电）、手机上有没有点
    「允许 USB 调试」、开发者选项里的 USB 调试是不是被系统自动关了、
    这台电脑是不是已经点了「信任」。安卓每次都问一遍是正常的，勾了"总是允许"就不问了。

问：提示跑哪去了？以前在左下角那行小字里。
答：都搬到窗口顶部中间那条胶囊里了（跟游戏模式开关同一条），
    一次只显示一条，两秒多自己淡出。

问：窗口每次开都跑到左上角 / 尺寸不对？
答：现在打开就居中（按你主屏的可用区域算，任务栏不算进去）。
    窗口大小能拖，位置不记忆，每次都在正中。

问：截图里有账号，想发出去怎么办？
答：素材页右键那张图 ->"打码（遮住账号 / 昵称）"-> 在图上按住左键拖几块
    ->"打码并保存"。同目录会多一张"原名_打码.png"，原图原封不动。

问：不想用了怎么彻底删干净？
答：先托盘右键"全部还原"（回原生分辨率、还原 ACE、关灯、停回放），
    再关掉 设置 -> 通用 里的开机自启，然后整个删掉程序文件夹。
    配置（config.json）和素材（素材\）都在里面，删了不可恢复 ——
    想留着就单独拷出来。回放缓存那块盘（默认在程序目录"回放缓冲"，
    也可能被你换到 D/W）也要删掉，不然白占 5-10 GB。

问：自动化点了"试运行"，怎么什么都没变？
答：这就是试运行的用意 —— 它只把每一步会做什么打出来，一个动作都不执行，
    方便先看顺序对不对。要真跑点"立即执行"（会先问你一句）。

问：接了两台显示器，切档只动一块？
答：分辨率卡下面那行"作用屏幕"选的就是作用对象，选哪块就动哪块。
    换屏时会重读那块屏的原生分辨率；单屏时这行不出现。

问：热键按了没反应？
答：设置 -> 热键，右边那列是真正生效的键。写"注册失败"=没抢到；
    写黄色"生效 xxx"=被别的软件占了、程序自动换了备用键；
    写"已关闭"=这一行的勾被你去掉了。

问：录出来的视频没声音？
答：录屏抓的是系统回环声音（不含麦克风）。确认放的时候系统有声音在响；
    已经录好的文件补不了，得重录。

问：录像点开打不开？
答：录制中途被强杀或断电，mp4 没写完（缺 moov，所以十几 MB 也打不开）。
    素材页会直接标"读取失败"、卡片写"坏档"；顶部下拉选"坏档"能把它们一次挑出来删掉。
    这种修不回来，删了重录。

问：会不会封号？
答：不注入游戏、不读写游戏内存、不改游戏文件。ACE 那项只是把反作弊进程的
    优先级压低、亲和性收到一个核，扫描照常进行 —— 是"让扫描排在游戏后面"，
    不是"把扫描挡死"。要不要用自行判断。

问：杀毒报毒怎么办？
答：未签名的自写工具都会被这么提示。点"更多信息 -> 仍要运行"，或加信任区。
    程序不往网上传任何东西，日志和素材都在本地，可以自己翻。

问：换电脑怎么带设置？
答：设置 -> 高级 -> 导出配置；新机器上导入配置，重启生效。
    只想带工具就少走两步：工具页「⋯」→ 导出工具清单。

【已知边界】
- 分辨率默认只动主屏，多屏想切别的就在"作用屏幕"里挑
- 只列出系统真实支持的 4:3 模式，不会把屏幕切黑
- 网页类工具不接管浏览器进程，"停止"对浏览器无效（防止误关浏览器）
- 游戏内的渲染比例（比如 4:3 拉伸）是游戏自己的设置，这个工具只改桌面分辨率
- 投屏依赖 adb + scrcpy（随包带了），手机那头不用装 App，但第一次开 USB 调试
  必须插线；安卓 11 以上第一次切无线也要插一次线
- Steam 库读的是本机 Steam 的记录，没装 Steam 或换账号读不到别人那份
- 喜加一只列、只跳转，不登录不代领
