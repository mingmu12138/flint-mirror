## 一、先记住这三件事

1. **双击桌面图标 = 打开面板，不会改你的分辨率**（防误触）。
2. 想秒切分辨率，按 `Ctrl + Alt + R`，或者在面板上点那个大按钮。
3. **点右上角的 × 只是收进托盘**，程序还在后台跑。要真退出，右键托盘图标 → 退出，或在面板「设置」里关掉「关闭窗口时收进托盘」。

**托盘右键前五项就是状态开关**：帧率悬浮窗 / 回放缓冲 / 录屏 / ACE 限流 / 每日密码悬浮窗，勾着 = 开着，点一下就切。不用开面板就能一眼看出现在什么在跑，也不用为了关个灯专门把面板调出来。

## 三、分辨率

### 三种触发方式

| 方式 | 操作 | 速度 |
| --- | --- | --- |
| 面板按钮 | 点「切换为 16:10」/「切回原生」 | 瞬时 |
| 全局热键 | `Ctrl + Alt + R` | 瞬时 |
| 托盘右键 | 分辨率那一条，文字跟着状态变 | 瞬时 |

按钮上只写比例（`切换为 16:10`），完整数值在右边的下拉里，选中就切；已经在目标档时按钮变成「切回原生」。

其它按钮：**以当前为原生**（换屏后重记基准）、**自定义…**（输入枚举外档位，先试探再切）、**刷新**。

### 档位分组

下拉按宽高比分组，原生单独一组放最上面，带 ★ 的是常见游戏推荐档。程序只列你这块屏真实支持的模式，切不了的直接提示，不会硬切黑屏。

### 首次运行的自动推荐

第一次运行（或换电脑后）程序会读你的原生分辨率和刷新率，自动推荐一个**同比例**的档位，避免一上来就黑边：

| 你的屏幕 | 推荐档 |
| --- | --- |
| 1K（1920 × 1080 这类） | 1600 × 900 |
| 2K（2560 × 1440 这类） | 1920 × 1080 |

推荐结果会写进 `config.json` 的 `target`，你手动改过一次之后就固定，不会再被覆盖。

### 嘉豪模式（4:3 拉满、去黑边）

勾选框会实时读显卡缩放状态：

- 原生档 → 「原生档，不用拉伸」
- 4:3 且显卡是「保持宽高比」→ 「左右有黑边」，提示你去显卡设置
- 4:3 且显卡是「拉伸/全屏」→ 「拉伸铺满 · 无黑边」

**它还会读你用的什么线、多少刷新率，直接说你这台属于哪种情况**：

| 读到的情况 | 判断 |
| --- | --- |
| DisplayPort | 去显卡面板把缩放设备改成 GPU、模式全屏，一般就能铺满，不用换线 |
| HDMI 且 ≥ 120Hz | GPU 缩放大概率被驱动关掉了（DSC 占用带宽），换 DP 线；临时想铺满就游戏内设 4:3 + 独占全屏 |
| 其它 | 先试显卡面板的「全屏 / 拉伸」，改不动再用游戏内 4:3 |

点「嘉豪模式」勾选时弹的窗里，第一行就是「【这台的情况】…」，不用自己猜。

**去黑边那一下只能在显卡面板点一次**（Windows 不让外部程序改这个），点「去显卡设置」会按你选的厂家打开对应软件。改完是全局持久的。画面横向变宽不是 bug，是 4:3 拉伸本身。

**多屏用户**：接了两台以上显示器时，分辨率卡下面会自己冒出一行「作用屏幕」+ 下拉框。选哪块屏，切档、回原生、自动化就都只动那一块，另一块完全不动。切到副屏时会顺手重读那块屏的原生分辨率（每块屏不一样），存进配置，下次启动自动接上。单屏时这一行不出现。

## 四、战斗工具：截图、录屏、回放

| 键 | 作用 |
| --- | --- |
| `Ctrl + Alt + S` | 全屏截图（自己先躲开，截完回来） |
| `Ctrl + Alt + Shift + S` | 框选截图（也可以设 3 秒延迟） |
| `Ctrl + Alt + V` | 开始 / 停止录屏 |
| `Ctrl + Alt + B` | 保存最近 10 分钟 |

- **录屏**：Qt 采集画面 + WASAPI 抓系统声音，最后用 ffmpeg 并轨，**成片是有声的**。
- **回放**：后台循环缓存最近 10 分钟（分段写盘），你按下保存才真正落盘，平时占不了多少地方。
- **归档**：素材按 `素材\录像\YYYY-MM-DD\` 分日期存放，哪天哪场一眼能找回来。
- **帧率悬浮窗**：独立开关、可拖动、独立鼠标穿透；低帧会变色。一直显示 `--` 时用管理员身份跑一次（它靠 PresentMon 读真实帧）。

### 素材页能干什么

点顶部「素材」进素材库，按日期一行一组：

| 想做的事 | 怎么做 |
| --- | --- |
| 找某一场 | 右上角搜索框输文件名片段（`16-30`）、日期（`2026-11-18`）或类型（`录像`），边打边筛 |
| 看这次录了多大 | 顶部汇总写「11 个 · 70.0 MB」，每天都标自己的占用（`2 个 · 13.1 MB`） |
| 找带声音的那段 | 顶部下拉选「有声录像」，只剩有音轨的；想反过来看静音就选「静音录像」 |
| 这段多长时间 | 录像卡片第二行直接写 `0:20 · 有声 · 19.7 MB`，不用点开播放器 |
| 一眼认内容 | 截图和录像都出缩略图；录像的封面是后台用内置 ffmpeg 抽的第一帧，不会卡界面 |
| 清当天的 | 每行右边「删这一天」，整组顺手清掉 |
| 清旧的 | 顶部「清理旧素材」，问你要删多少天以前的，把总量算给你看再动手 |
| 单张处理 | 双击打开，右键「在文件夹中显示」或「删除」 |
| 发出去前遮账号 | 截图右键「打码（遮住账号 / 昵称）」→ 在图上拖一块要遮的地方 → 「打码并保存」 |

**每段录像的时长和有没有声音，卡片上直接写**：`0:20 · 有声 · 19.7 MB` / `0:05 · 静音 · 3.4 MB`。
时长是扫 mp4 自己的头部读出来的（不调 ffprobe、不解码，几百段也是一瞬间），**不看你有没有装解码器**。
"有声"= 这段里有音轨；"静音"= 录的时候没抓声音（接了内嵌 ffmpeg 之后正常录都有）。鼠标悬停卡片能看完整信息。

**坏掉的录像会标「读取失败」+ 卡片写「坏档」**：录到一半断电/强杀进程，mp4 没写完（缺 moov，`14-24-50_录像.mp4` 就是 13.5 MB 却打不开），这种文件打不开也修不回。顶部下拉选「坏档」可以把这些一次挑出来删掉。

**筛完的汇总跟着变**：选中「有声录像」后顶部写「筛出 2 个 · 13.1 MB」，不会出现"2 个文件却 70 MB"这种自相矛盾的数字。

缩略图缓存在 `素材\.thumbs\`，删掉不影响素材本身，下次自动重建；素材没了它也会自己清掉对应的缓存图。

**窗口拖窄了也不会裁掉右边**：顶栏按钮会自动折成两排，素材卡片按窗口宽度从 4 列变成 3 列，分辨率那张卡的目标下拉和「切换为 X」大按钮各占一行。最小能拖到 660 宽。

### 素材想放到 D 盘 / 别的文件夹

默认全在程序目录的 `素材\`。要换地方：**设置 → 高级 → 素材存放位置**。

- 下拉里列着每块盘的剩余空间，选一块就是 `<那块盘>\燧镜素材`；
- 「选文件夹…」可以指到任意目录（比如 `D:\游戏\三角洲素材`）；
- 「恢复默认」回到程序目录下的 `素材`。

**换的时候旧素材怎么办**：如果旧位置已经有东西，会弹一句话问你——
- 「一起搬过去」：文件和 `截图\日期` / `录像\日期` 的目录结构原样过去，进度条可以取消；重名或读不动的会跳过并报个数，搬完把旧目录里空掉的文件夹收走；
- 「只换位置，旧的留着」：以后新素材进新位置，旧的留在原处（素材页就只显示新位置的了）。

换完素材页立刻按新位置重新列，不用重启。

**回放缓存是另一回事**：它只存最近 10 分钟的分段临时文件、不是成品，所以「缓存盘」是单独一项（就在素材位置上面一行），想让它也挪到同一块盘，改那一项就行。

**截图里有账号 / 昵称，想发出去怎么办**：右键那张图 →「打码（遮住账号 / 昵称）」，弹出一个大图窗口，**按住左键拖一块区域**就是一块马赛克，可以拖好几块（拖歪了点「撤销一块」）。保存后同目录多一张 `原名_打码.png`，**原图原封不动**，确认没问题再自己删。马赛克是"缩小再放大"的真糊，不是盖个半透明框——文字和数字都会被搅散。

### 回放缓存占多大、写在哪块盘

回放是 10 秒一段循环写盘的，默认只留最近 12 分钟（够取 10 分钟），另外还有体积上限：

- 上限可选 **5 / 7 / 10 GB**（设置 → 高级 → 回放缓存）；超了就从最旧的段开始删，但永远至少留够 11 分钟，不会为了省地方把能用的删掉
- 缓存盘可以换到 D / W 这类非系统盘（设置 → 高级 → 缓存盘），默认在程序目录的 `回放缓冲\`
- 这一段只是临时缓冲，不是成品；按保存后成片在 `素材\录像\日期\`
- **临时音轨不会留在素材目录**：录屏时的声音先单独写一段 wav，停止后合进 mp4；合完就删，合不进去（视频是坏的）也删，不会在 `素材\录像\` 里留一堆 `_audio.wav`

## 五、三角洲情报

顶部「三角洲」进情报页，数据源 `shushu.fan`，**全部手动刷新**（不频繁打人家网站）：

## 六、自动化

1. 点顶部「自动化」→ 上面紫色的 **一键模板**
2. 点「两条一起加」，就有了一套开战/收尾流程：

- **A 开战准备**：等 30 秒 → 限 ACE → 开帧率灯 → 开回放缓冲（**不动分辨率**，保持原生）
- **B 收尾归档**：存最后一段回放 → 关回放 → 关帧率灯 → 还原分辨率

### 三种触发

| 触发 | 什么时候跑 | 典型用法 |
| --- | --- | --- |
| 当进程启动 | 检测到某个进程出现 | 三角洲启动 → 做准备 |
| 当进程退出 | 检测到某个进程消失 | 游戏退出 → 存回放、还原 |
| 仅手动执行 | 只有你点「运行」才跑 | 一键清缓存、临时切档 |

进程名要写**真名**（任务管理器「详细信息」里那一列），`DeltaForceClient` 这类，别写窗口标题。

### 18 种动作

| 动作 | 参数 | 干成什么样 / 失败会怎样 |
| --- | --- | --- |
| 切换分辨率 | `1680x1050` 这种 | 切到指定档；这台屏不支持就跳过并记一行日志，硬切黑屏是不会发生的 |
| 恢复原生分辨率 | 无 | 回到原生基准档 |
| 启动工具 | 工具 id | 拉起对应 exe；工具路径没了就跳过 |
| 停止工具 | 工具 id | 结束该进程；网页类工具不接管浏览器，会明确写「不接管」 |
| 等待 | 秒数 | 空转等待，用来给游戏加载留时间 |
| 限制 ACE 扫盘 | 无 | 压低优先级 + 单核亲和 + 低 IO；**要管理员**，没权限会提示 |
| 解除 ACE 限制 | 无 | 恢复原来的优先级与亲和 |
| 开 / 关帧率悬浮窗 | 无 | 开关那个小灯 |
| 显示 / 隐藏密码悬浮窗 | 无 | 开关每日密码 HUD |
| 开启 / 关闭回放缓冲 | 无 | 后台循环录最近 10 分钟；缓存盘和上限按设置来 |
| 保存最近回放 | 无 | 把当前缓冲落盘成 mp4（要几秒，界面会提示） |
| 开始录屏 | 无 | 开始有声录屏，文件进 `素材\录像\日期` |
| 停止录屏并保存 | 无 | 停并合成音轨，顺带删临时 wav |
| 截一张图 | `全屏` / `框选` | 截到 `素材\截图\日期` |
| 清理着色器缓存 | 无 | 删显卡与 DX 缓存，清完第一次进游戏会重编译 |

**失败一律是「跳过这一条，继续往下跑」**，不会因为一条失败卡死整套流程；每条的执行结果都写进面板下方的运行记录。

### 「试运行」和「立即执行」是两件事

| 按钮 | 干什么 | 会改分辨率吗 |
| --- | --- | --- |
| **试运行** | 把每一步会做什么一条条打出来，**一个动作都不执行** | 不会 |
| **立即执行** | 真的跑一遍，会切档、启停工具 | 会，所以会先问你一句 |

试运行的日志长这样，一眼看出顺序对不对、有没有哪步其实不会生效：

```
「开战」〔试运行〕切到 1680×1050
「开战」〔试运行〕等 30 秒（试运行不等）
「开战」〔试运行〕面板动作：ACE 一键限制（试运行不会真点）
「开战」〔试运行〕启动 灵引系统
「开战」试运行结束（什么都没改）
```

它还会替你把"这步其实没用"标出来，比如「恢复原生 1920×1080（本来就在，不会动）」「切到 1680×1050，和现在一样不会动」。

第一次启动会自动弹 4 页引导（设置里「新手引导」可重看）。

## 七、设置里有什么

| 分类 | 里面有什么 |
| --- | --- |
| 通用 | 开机自启、关闭窗口是否收进托盘 |
| 热键 | 全局热键总开关 + 每行单独开关 + 实际生效的键 |

| 音频 | A / B 两台输出设备、测试切换 |
| 高级 | 回放缓存上限与缓存盘、打开程序目录、日志、新手引导、导出 / 导入配置 |

**每行前面的勾是单独开关**：去掉勾这一个键就不响应，别的照常用；勾回来键位还是原来那个，不用重录。按钮点一下再按组合就能改键，按 `Esc` 取消。

**右边那列是真正注册上的键**：跟左边一致显示灰绿色；被别的软件占了会自动用备用键并标黄（鼠标悬停看原因）；一个都没注册上直接写「注册失败」。

换电脑时用**导出配置 / 导入配置**把热键、工具、档位这些带走，导完重启生效。

| 动作 | 默认键 |
| --- | --- |

| 打开控制面板 | `Ctrl + Alt + M` |
| 全屏截图 | `Ctrl + Alt + S` |

| 保存最近回放 | `Ctrl + Alt + B` |

## 八、工具卡

| 功能 | 说明 |
| --- | --- |
| 着色器缓存 | 「统计」看能清多少，「一键清理」删掉 NVIDIA / AMD / Intel 与 DirectX 的缓存。赛季更新后卡顿时用；清完第一次进游戏会重编译着色器，前一两分钟略卡之后更顺 |
| 网络测速 | 判断卡顿是网络还是机器 |
| 系统更新 | 「推迟 35 天」把 Windows 自动更新往后挪，和系统里「暂停更新」是同一套设置，到期自动恢复，不是永久关闭。改注册表需要管理员权限 |

游戏里最怕打到一半被更新拽下去，进游戏前点一下就行。

### 网络测速怎么读

点主界面工具卡的「开始测速」，它做两件事：

1. **连续采样 12 秒**（每 0.5 秒打一次国内节点），边跑边显示 `采样 14/24　当前 18 ms　平均 20 ms　抖动 9 ms　丢包 0%`
2. 采样完再测下载带宽
3. 如果你在 设置 → 高级 里填了**游戏服务器地址**（`host` 或 `host:端口`），再额外打它 6 秒，单独出一行：`游戏服 xxx：平均 32 ms · 抖动 5 ms · 丢包 0%`

结果两行，第二行是**人话判定**：

| 判定长这样 | 意思 | 该动什么 |
| --- | --- | --- |
| 丢包 ≥ 8% | 网络在丢包 | 换有线、重启路由器、别用校园网 |
| 抖动大（平均不高但最高很高） | WiFi 干扰或后台在下载 | 关同步、离路由器近点 |
| 延迟 ≥ 90 ms | 天生不适合 FPS | 换有线、选就近服务器 |
| 网络很稳 | 延迟低、抖动小、不丢包 | **别怪网络了，去查显卡占用 / 温度 / 帧率灯** |

填了游戏服还多一层判断：公共节点很稳、游戏服却高出 40 ms 以上，会直接提示「到服这段绕远了——换加速器节点或换区服，比换宽带有用」。这个差距是公共测速看不出来的。

也就是说：以前测速只告诉你「多快」，现在告诉你「卡的时候该骂谁」。

## 九、出问题先看这里

**出任何事先点「全部还原」**：右键托盘图标 → 「全部还原」（出问题先点这个），或 `燧镜.exe --panic`。顺序是：录屏先保存并停掉 → 关回放缓冲 → 关帧率灯 → 关密码悬浮窗 → ACE 全部还原 → 分辨率回原生。本来就在默认状态时它会直接说「本来就在默认状态」，不会瞎动。

**分辨率切错了 / 屏幕变糊 / 想强制回去**：双击根目录的 `恢复分辨率.bat`。这个入口不加载界面，主程序卡死也能把分辨率恢复。

**其它状况**：

- ACE 限制不生效 → 需要管理员权限，右键快捷方式「以管理员身份运行」，重启后静默待在托盘
- 自动化没触发 → 九成是进程名写错，去任务管理器「详细信息」那一列复制真名
- 帧率灯一直是 `--` → 管理员身份跑一次
- 换电脑 / 换显示器 → 程序自动只更新"原生"基准，**不会自己去改当前分辨率**
- 系统更新推迟失败 → 同样要管理员权限

**被杀毒拦了、或要反馈误报**：顶部「关于」里有两行文件指纹——`燧镜.exe · 8.0 MB · 时间` 和 `SHA256 xxxxxxxx…`，旁边「复制指纹」一键复制。把这两行发出去，对方能核对是不是同一份文件，比截图有用。

**还搞不定**：点顶部「日志」——右上角直接标「正常」或「有错误」；点「导出诊断包」会打成一个 zip 并自动帮你选中，把里面内容发出来能定位到具体哪一步。

## 九点五、更新日志与卸载

### 这次改了什么

关于页右下角「更新日志」，按日期列出每次动了什么（只写用起来能感觉到的，内部整理不占篇幅）。升级时把 `App` 整个文件夹替换掉，**`config.json` 和 `素材\` 别删**——配置和素材都在里面。

### 想彻底删干净

按顺序来，删完就一根毛都不剩：

| 要删的 | 位置 | 说明 |
| --- | --- | --- |
| 程序本体 | 安装目录整个文件夹（默认在 `%LOCALAPPDATA%\Programs\燧镜`） | 含 exe、依赖、日志 |
| 你的配置 | 安装目录里的 `config.json` | 不删就在里面；想换电脑带走它就够了 |

| 注册表 | 一般不写；只有 `恢复分辨率.bat` 用过才可能留下显示设置 | 卸载前先点托盘「全部还原」最稳 |

**卸载前先做一件事**：托盘右键 →「全部还原」（回原生分辨率、还原 ACE、关灯、停回放）。它不依赖程序还在不在，但能保证你屏幕回到正常状态，省得后面自己手忙脚乱。

## 十二、分发版

`build_dist.py` 生成的干净副本和你本机 `App` 的差别只有三点：

1. `config.json` 的 `native` 是 `[0,0,0]`、`mods` 为空——不带你的分辨率和路径
2. 对方第一次运行会把他那台机器的当下分辨率记成基准，候选档位按他那块屏现枚举；如果他那边的当前分辨率跟面板最大对不上（自己改过分辨率或缩放），程序会先问一句「按面板最大记，还是按当前记」，不会闷头记错
3. 附带 `使用说明.txt` 和 `恢复分辨率.bat`

**整个文件夹 / 整个 zip 一起给**，只发 exe 打不开。首次运行可能被 SmartScreen 或杀软拦，是未签名自写工具的常态，点「更多信息 → 仍要运行」或加信任区。

## 十三、ACE 扫盘限制

腾讯 ACE 后台扫硬盘时跟游戏抢 CPU 和磁盘，表现就是掉帧、鼠标一顿一顿。Cards 里那张「ACE 扫盘限制」做三件事（`SGuard64.exe`、`SGuardSvc64.exe`、`ACE-Tray.exe` 都能自动认出来）：

- 进程优先级拉到最低
- CPU 亲和性只留一个逻辑核
- 磁盘 I/O 优先级降到最低

**扫描照常进行，反作弊不受影响**，只是让它排在游戏后面。特意没有做「禁止读取」那种做法——真把扫描挡死容易触发安全组件异常，风险不值得。

用法：启动游戏 → 点「一键限制」（要管理员权限）→ 嫌麻烦就勾「自动守护」，游戏重启 ACE 后会自动再压一次 → 想恢复点「还原」。

## 十四、已知边界

- 只处理主显示器，多屏不逐个切
- 只列系统真实支持的模式，不会切黑屏
- 网页类工具不接管浏览器进程，「停止」对浏览器无效
- 游戏内渲染比例是游戏自己的设置，这里只改桌面分辨率
- 改分辨率、改注册表、改 ACE 优先级都需要管理员权限
- 哈夫币战绩页需要你在内嵌页面里自己登录，程序不接触密码

## 十五、音频输出一键切换

耳机和音箱来回切，不用再点任务栏那个小喇叭翻找：

| 怎么切 | 操作 |
| --- | --- |
| 热键 | `Alt + Z`（和 NVIDIA 覆盖层默认键撞了的话，会提示并用备用键，设置 → 热键 里能看到实际生效的键） |
| 托盘小喇叭 | 双击就切；图标会跟着当前设备变（耳机 / 音箱两种形状） |
| 面板 | 顶部「音频」按钮点一下 |
| 指定切换 | 右键托盘小喇叭 → 「切到 A」「切到 B」 |

- 设备**不写死名字**，装到别人电脑上由对方在 设置 → 音频 里选 A、B 两台（选成同一台会拒绝）
- 切换时**屏幕左上角飘一张卡片**，写着切到了什么设备，2 秒自动淡出，鼠标能穿过去，不挡游戏
- 设备拔了 / 没开机 → 不切，提示「没找到那个设备」，不会把声音切到虚空
- 两个设备位存在 `config.json` 的 `audio_a` / `audio_b` 里，跟着配置一起迁移

## 十七、常见问题 FAQ

### 画面 / 分辨率

**切完变糊了怎么办**
先按 `Ctrl + Alt + R` 回原生；按不动就双击根目录的 `恢复分辨率.bat`（不加载界面，主程序卡死也能用）；还不行就右键托盘 →「全部还原」。

**切完两边有黑边**
这是显卡缩放设成「保持宽高比」了，程序改不了（Windows 不让）。点面板上「去显卡设置」，在 NVIDIA / AMD 面板里把缩放模式改成「全屏」或「拉伸」，改一次全局生效。

**画面横向变宽、看着变形**
4:3 拉伸本来就是这样的，不是程序切坏了。

**换电脑 / 换显示器会不会把分辨率搞乱**
不会。程序只会更新「原生基准」，绝不主动改当前分辨率。如果对方的当前分辨率和面板最大对不上，首次运行会先问一句按哪个记，不会闷头记错。

### 热键

**按了没反应**
看 设置 → 热键 右边那列：写「注册失败」是没抢到；写黄色「生效 xxx」是被别的软件占了、程序自动换了备选键；写「已关闭」是你把这一行的勾去掉了。

**Alt+Z 不管用**
常见是 NVIDIA 覆盖层占了。设置里能看到实际生效的键（多半是 `Alt+Shift+Z`），也可以自己改成顺手的。

**想只用其中几个热键**
每行前面的勾去掉就行，不影响别的。

### 录屏 / 回放

**录出来没声音**
录屏会抓系统回环声音（不带麦克风）。先在系统里确认有声音在放；如果整段都没声，看日志有没有「音轨合并失败」。已经录好的文件补不了，得重录。

**回放保存很慢**
要把内存里的分段合成一个 mp4，10 分钟大概几秒到十几秒，界面会提示「正在合成」，别以为卡死了。

**素材目录里一堆 `_audio.wav`**
旧版本才会留。现在合成了就删，合不进去也删，不会再堆。

**录像点开打不开 / 素材页标「读取失败」**
录制中途程序被强杀或断电，mp4 没写完，这种修不回来，直接删掉重录。

### 工具 / 模组

**一次起好几个，谁先谁后？**
点「全部启动」，按**列表从上到下**的顺序一个一个来，每个之间隔 0.8 秒——前一个先站住，后一个再起（有些工具一起挤上来会抢资源）。想让某个先起，把它在列表里排前面就行。已经跑着的不重复启动。

**自带的都有哪些**

跟软件一起打包的（路径不用你配）：

| 名字 | 在哪一页 | 干什么 | 说明 |
| --- | --- | --- | --- |
| 口琴可视化曲谱 | 模组 | 练口琴时有谱有音 | 做成了 `.sjmod` 模组，能力跟原来一模一样 |
| 手机音频接收 | 工具 | 手机蓝牙连电脑，把手机的声当电脑输出 | 蓝牙 A2DP Sink，卡片带「内置」角标 |
| **qBittorrent** | 工具 | BT 下载（挂种子、边玩边下） | 4.6.5，见下 |
| 三角洲情报 / 显示器滤镜 | 工具 | 每日密码、子弹价格；18 个滤镜预设 | 页面类内置工具，点开直接切页 |

**qBittorrent 为什么不像别的软件那样乱写磁盘**：它启动时带一个 `--profile=profile` 参数，配置、缓存、种子列表全部落在 `bundled\qbittorrent\profile\` 里，**不写 `%APPDATA%`、不注册服务、不建快捷方式、不关联 .torrent 文件**。换电脑拷整个文件夹过去，下载记录和设置都跟着走；不想用了直接把 `bundled\qbittorrent` 删掉，系统里一点残留都没有。

首次打开已经帮你跳过了两个烦人的弹窗（法律声明、检查更新），界面是中文。它默认把下载的东西放系统「下载」文件夹，想换地方在 qBittorrent 自己的「设置→下载」里改。

qBittorrent 是 GPL-2.0 授权的开源软件（未改二进制分发），许可证和源码地址写在 `bundled\qbittorrent\LICENSE.txt`。下载什么内容自己判断合不合规。

**工具点了启动没反应 / 一闪就没了**
现在它会自己查，不用你猜。卡片（图标视图是格子）下面的状态有四档：

| 状态 | 什么意思 | 怎么办 |
| --- | --- | --- |
| ● 未运行 | 没启动过，或者被你停了 | 正常 |
| ● 运行中 | 进程活着 | 正常 |
| ● 文件丢失 | 那个 exe 不在原位了 | 换过盘/挪过目录，右键编辑重新指一下 |
| ● 启动失败（红字） | 起来了但马上退了，或根本没起来 | **鼠标悬停那一行**，原因就在提示里 |

「启动失败」给出的原因都是人话，常见的几种：

- `缺运行库（.NET Framework 或 VC++ 运行库没装）` → 装 VC++ 运行库
- `加载 DLL 失败` → 重装运行库，或别把它放在中文深层目录
- `权限不足，需要管理员` → 右键燧镜「以管理员身份运行」
- `正被别的程序占用` → 先把那个旧进程关掉
- `不是能在本机跑的程序` → 下错版本（32/64 位、或下成了别的系统），换对应那份
- `找不到文件` / `找不到它依赖的文件` → 别把它从原目录挪走，它依赖同目录的 dll

启动后燧镜会等约 1.2 秒回头看一眼，所以「一闪就没」这种情况能被抓住，不用你盯着。

**没起来会自动再试一次**：不少工具第一次启动要拉运行库、拉子进程，慢半拍的会假失败。所以第一次失败不会立刻判死刑——隔 0.9 秒再拉一次，还是不行才标红，并在原因后面标「已自动重试过一次」。手工再点一次启动，重试机会会重新给。

每次都写进日志，出问题点「导出诊断包」就能带出来。

网页类工具点「停止」无效是正常的——框架不接管浏览器进程，防止误关整个浏览器。

**三方工具是什么**
没下载的工具（Steam、图吧工具箱、Epic、PCL2、KOOK、OOPZ 这类）挂在工具页横线下面，标着「三方工具」。点一格就去官网；如果在添加时填了直链，就由燧镜下载到 `文档\燧镜\tools\名字\`，下完自动变成普通工具，能直接启动。图标是燧镜去官网抓的，抓一次存在 `cache\favicons\`，之后离线也有。

### 音频

**托盘找不到那个小喇叭**
Win11 的「其他系统托盘图标」是按应用聚合的，同一程序只显示一条。小喇叭可能被折叠在 `^` 溢出菜单里；就算找不到，右键主托盘图标的「音频输出」也能切，热键同样能用。

**接了两台显示器，只有主屏变了**
现在可以挑：分辨率卡下面有一行「作用屏幕」下拉，选哪块就切哪块，别的屏不动。选副屏时会顺手重读那块屏的原生分辨率（每块屏不一样），下次启动自动接上。下拉没出现 = 只接了一块屏。

**任务栏没有 `^` 箭头了**
说明溢出区是空的：所有图标都被设成「始终显示」。在 设置 → 个性化 → 任务栏 → 其他系统托盘图标 里，把任意一个正在运行的程序那一栏关掉，它就会回到溢出菜单，箭头随之出现。

### 权限与杀毒

**为什么老要管理员**
改分辨率、改注册表（推迟更新）、调进程优先级（ACE）、读显卡温度都要权限。以管理员身份跑一次并勾开机自启，之后静默待托盘。

**杀毒报毒 / SmartScreen 拦截**
未签名的自写工具都会被这么提示。处理方式：Windows 弹窗点「更多信息 → 仍要运行」；杀软把它加信任区。程序不联网上传任何东西，日志和素材都在本地，可以自己翻。

要证明「没被别人改过」，打开顶部「关于」，有一行 `SHA256 …`，点「复制指纹」就能拿走，发给别人核对。

**会不会被封号**
程序**不注入游戏、不读写游戏内存、不改游戏文件**。ACE 那项只是把反作弊进程的优先级压低、亲和性收到一个核，扫描照常进行。它做的是「让扫描排在游戏后面」，不是「把扫描挡死」。要不要用自行判断。

### 素材与数据

**清理旧素材会不会删到我自己放进去的东西**
只动 `素材\截图` 和 `素材\录像` 两个目录里的图片和视频，按你说的天数删。你自己丢进这俩目录的文件同样算在内，删之前会把数量和总大小摊给你看。

**换电脑怎么把设置带走**
设置 → 高级 →「导出配置」，到新机器上「导入配置」，重启生效。素材和缓存不会跟着走。

**日志在哪**
程序目录里的 `logs\app.log`（安装版在安装目录下，解压版在程序文件夹下）。点顶部「日志」→「导出诊断包」会打成 zip 并自动选中，发出来最快定位。

## 源码与重新打包

这个文件夹是源码，不是给用户用的程序目录。给别人发的是 `燧镜_v1.10.1_安装包.exe`，或者 `分发版\燧镜` 整个文件夹。

| 文件 / 目录 | 干什么的 |
|---|---|
| `gui.py` | 主界面、素材页、三角洲页、设置对话框、自动化面板 |
| `core\` | 分辨率、ACE 限流、录屏回放、帧率悬浮、音频切换、配置读写 |
| `launcher.py` | 入口；也带 `--shot` `--shot-about` `--panic` 等自检参数 |
| `assets\` | 图标和静态资源，打包时 `--add-data` 带进去 |
| `bundled\` | 内置工具（手机音频接收、qBittorrent）+ ffmpeg + PresentMon。**别删**，删了内置工具和回放都起不来 |
| `installer.nsi` | 安装包脚本：界面文案、默认装哪、快捷方式、卸载时问不问删素材 |
| `build_dist.py` | 生成 `分发版\燧镜` 和 zip，并往里写一份干净默认 `config.json` |
| `build_installer.py` | 调 NSIS 出安装包 |
| `_nsis\` | 绿色版 NSIS 编译器，**别删**，没它编不出安装包 |
| `version_info.txt` | exe 的版本号、发布者、版权信息 |
| `.venv313\` | Python 环境，删了得重新装 PySide6 才能打包 |
| `更新.bat` | 一键出包：打包 → 分发版 → 安装包，最后打开文件夹 |

### 出一个新版本

双击 `更新.bat` 就行。三步是串着来的：

1. PyInstaller 打包 → `dist\燧镜\燧镜.exe`
2. `build_dist.py` → `分发版\燧镜` + `燧镜_v1.10.1_分发版.zip`
3. `build_installer.py` → `燧镜_v1.10.1_安装包.exe`

**单独跑第 3 步会报「没有 分发版\燧镜」**，因为它吃的是第 2 步的产物，中间那步不能跳。

`dist\` 和 `build\` 是打包中间产物，占一到两个 G，随时可以删，下次打包自动重建。

### 关于 config.json

根目录这份 `config.json` 只在开发时跑源码用，里面可能带着你自己加的工具路径和分辨率。`build_dist.py` 写进分发版的是**干净默认配置**（只带内置条目、分辨率留空），所以发给别人不会出现「路径不存在」的工具。别人第一次启动时，程序会自动把内置工具补上。

### 这个文件夹里不要删的

`.gitignore` 已经把 `.venv313\`、`dist\`、`build\`、`分发版\`、`bundled\`、`logs\`、`网页登录\` 等目录排除在外，这些只在本机存在，不会进仓库。
